# ARC-01

## The Lantern Archive

**Audit · Repair · Contribute**

The Lantern Archive is a small learning-resource website prepared for the CSI VIT Chennai Technical Recruitment Project Challenge.

The project will be released in an unfinished state. Participants will explore it, document useful observations, make focused improvements, and explain how they verified their work. Clear reasoning and dependable changes matter more than the number of features added.

## What participants will do

- Fork and run the project.
- Investigate the visitor experience and codebase.
- Record at least two reproducible observations.
- Fix one problem that affects finding or downloading a resource.
- Make one additional focused improvement.
- Add or improve one repeatable check.
- Explain the completed work and any remaining limitations.

Findings may be documented through Issues, Discussions, Wiki pages, pull requests, or a short handover note. Final submission instructions will be shared through the official recruitment channels.

## Project status

The challenge repository is currently being prepared. Setup instructions and contribution guidance will be added before the project opens.

## Run locally

You need Node.js 22 LTS and npm.

```bash
npm install
npm run dev
```

Use `npm run typecheck` to check the TypeScript source and `npm run build` to create a production build.
