# Changelog

All notable public changes to ARC-01 will be recorded here.

The project follows small, reviewable checkpoints. Internal assessment notes and unfinished planning records are not published in this file.

## Unreleased

### Repository setup

- Initialized the ARC-01 repository with an empty README.
- Added repository hygiene and line-ending rules.
- Established public change tracking and a private local ticket ledger.

### Documentation

- Added the initial candidate-facing identity and challenge overview.
- Added final setup, investigation, submission, contribution, and assessment-use guidance.
- Added reusable Issue and pull-request templates.
- Improved the repository landing page with build status, command reference, project structure, and support links.

### Application foundation

- Added a minimal React, Vite, and TypeScript application.
- Added a responsive preparation screen without introducing optional frameworks or services.

### Visual system

- Replaced the gradient landing treatment with a flat banana-yellow, leaf-green, and carbon-black palette.
- Introduced a compact editorial layout inspired by classic WordPress blogs, with a masthead, menu, article column, sidebar widgets, and ruled borders.

### Resource catalogue

- Added five beginner-friendly technical guides with safe plain-text downloads.
- Added searchable and topic-filtered resource listings, detail pages, and predictable missing-page recovery.
- Added React Router as the only navigation dependency.

### Archive maintenance

- Added archive desk metadata and download feedback.
- Adjusted compact-screen shelf placement and archive navigation labels.

### Quality checks

- Added linting, type checking, focused interaction tests, and a GitHub Actions verification workflow.
- Updated the application toolchain to patched releases after a dependency security review.
- Declared the supported Node.js and npm runtime used by the candidate guide and CI.
- Completed the pre-release security, privacy, accessibility-boundary, and repository-leakage review.
